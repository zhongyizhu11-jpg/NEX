# NEX 自动换 IP

主机的公网 IP 被墙（这台机器连不上中国大陆）时，面板调用云厂商接口给它换一个公网 IP，入口地址和 DNS 跟着改。

## 这个插件做什么

自动换 IP 要拿着云账号凭据去调用云厂商接口，而 NEX 的插件只是一份声明文件，不能在面板后端运行代码。所以功能本身写在面板核心里，这个插件是它的**开关**：

- 安装并启用本插件（同时打开「插件功能」总开关）后，侧边栏出现「自动换 IP」入口，面板才开始下发探测、才允许更换。
- 停用或卸载本插件后，探测任务会从 Agent 上撤下，所有更换接口和定时任务都停止。已保存的云账号和主机配置保留在数据库里，重新启用后继续使用。

## 怎么判断被墙

- 探测由主机自己的 Agent 完成：定时向几个**只在大陆有节点**的目标发起 TCP 连接或 ping，不需要升级 Agent。
- 一轮里**所有**目标都不通才算一轮失败；任何一次成功都清零。
- 主机对面板离线时什么都不做（可能是面板侧网络问题，也可能是机器宕了）。
- 连续失败达到阈值（默认 5 轮、每轮 60 秒）后，打开了「自动更换」的主机会自动更换，没打开的只发通知。

## 安全兜底

- 同一台主机同时只会有一次更换。
- 冷却时间（默认 30 分钟）和每日上限（默认 3 次）只约束自动更换；「立即更换」不看冷却，但需要确认。
- 云厂商返回「可能已经生效」、调用超时，或面板在更换中途重启时，状态会变成「结果不确定」，在管理员确认并点「重置状态」之前不会再自动更换。

## 费用提醒

新申请的弹性 IP / 静态 IP 可能单独计费；旧 IP 如果没有释放，也可能继续计费。请在云控制台确认计费规则，必要时打开「换完释放旧 IP」。
