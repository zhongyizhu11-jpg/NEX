# Discord 登录和通知

NEX 可以接入 Discord 做两件事，两件事用同一个 Discord 应用，可以只开其中一件：

- **Discord 登录**：登录页多一个「使用 Discord 登录」按钮。默认只有**已经绑定过 Discord 的面板账号**能用；要不要让陌生的 Discord 账号直接注册新账号，由管理员决定。
- **Discord 通知**：一个只发私信的机器人。发给 Telegram 的那些通知（工单、规则异常、线路切换、主机上下线、自动换 IP、安全巡检、到期 / 流量提醒、每日简报），也会私信给绑定了 Discord 的人。

用户在 `个人资料 -> Discord` 里绑定一次 Discord，就同时有了登录和接收私信两样。

## 开始之前

- 面板要有一个固定的公开地址，并且是 **HTTPS**（`localhost` / `127.0.0.1` 本机调试除外）。在 `系统设置 -> 系统配置 -> 面板地址` 里填好并保存，例如 `https://panel.example.com`。Discord 自己允许 http 回调，但授权码和登录状态不能走明文，面板这边不放行。
- 面板服务器要能访问 `discord.com`。访问不了时，用户会看到「向 Discord 换取登录凭据失败」，测试消息会提示「连不上 discord.com」。

## 第一步：在 Discord Developer Portal 创建应用

1. 打开 [Discord Developer Portal › Applications](https://discord.com/developers/applications)，点 **New Application**，起个名字（比如「NEX 面板」）—— 这个名字和图标会显示在用户的授权页上。
2. 进入左侧 **OAuth2**：
   - **Redirects** 里点 **Add Redirect**，填入面板设置页显示的地址，**完全一致**：

     ```text
     https://panel.example.com/api/auth/discord/callback
     ```

     （就是「面板公开地址」后面接 `/api/auth/discord/callback`。设置页里有现成的一键复制。）保存。
   - 复制 **Client ID**（一串数字）。
   - 点 **Reset Secret**，复制 **Client Secret**。它只显示这一次，丢了就再 Reset 一次。
   - **Public Client** 保持关闭：面板是带密钥的「机密客户端」。

::: warning 面板公开地址改了，回调地址也要跟着改
回调地址是用「面板公开地址」拼出来的。换了域名或端口之后，要回 Developer Portal 把新的回调地址加进 Redirects，否则 Discord 会报 `Invalid OAuth2 redirect_uri`。
:::

## 第二步：在面板里开启 Discord 登录

进入：

```text
系统设置 -> 系统配置 -> Discord
```

| 选项 | 说明 |
| --- | --- |
| 启用 Discord 登录 | 总开关，默认关。没填面板公开地址、公开地址不是 https、没填 Client ID 或 Secret 时开不了 |
| 允许用 Discord 注册新账号 | 默认关：只有已经绑定过的账号能用 Discord 登录。打开后还要同时满足「开放注册」、邮件设置里的邮箱白名单和邀请码规则 |
| Client ID / Client Secret | 上一步拿到的两项。Secret 保存后只显示打码值，输入框留空 = 不修改 |
| 只允许这些邮箱域名 | 可选，逗号分隔，例如 `example.com, corp.example.org`。留空 = 不限。子域名也算。对登录、绑定、注册都生效 |

保存后，登录页就会出现「使用 Discord 登录」。

### 用户怎么绑定

1. 先用用户名 + 密码登录面板（要在「面板公开地址」打开的面板里）。
2. 打开 `个人资料 -> Discord`，点 **绑定 Discord**，在 Discord 页面点「授权」。
3. 回到个人资料，显示「已绑定」和对应的 Discord 用户名。以后在登录页点「使用 Discord 登录」即可。

解除绑定也在这里。解除前要确认账号还有别的登录方式：用 Discord 注册的账号一开始没有密码，要先在同一块里 **设置登录密码**（或者添加通行密钥），才能解除绑定。

### 账号怎么对应

- 面板只认 Discord 账号的 **用户 ID**（一串数字，永远不变），不认用户名，也不认邮箱。Discord 用户名、邮箱改了，绑定不受影响；面板里显示的用户名和邮箱会在下次登录时更新。
- 面板向 Discord 要的权限只有 `identify`（用户 ID 和用户名）和 `email`（邮箱）。Discord 账号的邮箱必须是**已验证**的，否则不能用来登录或注册；用户在授权页上把邮箱权限去掉也一样。
- **不会按邮箱自动合并账号。** 一个没绑定过的 Discord 账号，哪怕邮箱和某个面板账号一模一样，也不会直接登录进那个账号 —— 会提示「这个 Discord 账号还没绑定面板账号：请先用密码登录，在 账号设置 里绑定 Discord」。
- 允许注册时，新账号的用户名取 Discord 用户名（被占用就加数字，比如 `alice2`），邮箱记为已验证，权限和自助注册的新用户一样。这个邮箱已经是某个面板账号的用户名或邮箱时，不会再建一个新账号，同样提示去绑定。
- 一个 Discord 账号只能绑定一个面板账号，一个面板账号也只能绑定一个 Discord 账号。
- 停用的账号、维护模式，和密码登录的规则完全一样。
- 开了 [邀请返利](./referrals.md) 时，从邀请链接打开注册页再点「使用 Discord 登录」，邀请码会一起带过去（App 里也一样），新账号照样记上邀请人。开了「必须邀请注册」时，没有有效邀请码的 Discord 账号不能注册新账号。

### 双重验证

账户开了双重验证（2FA）时，用 Discord 登录之后**仍然要输入 2FA 验证码**。Discord 账号被盗不应该绕过面板自己的 2FA。

### 在 App 里使用

App 里点「使用 Discord 登录」会打开**系统浏览器**：

1. 在浏览器里授权 Discord；
2. 看到「请回到 NEX App」后切回 App，几秒内自动登录（App 每两秒问一次面板）；
3. 如果浏览器和 App 的网络出口 IP 不一样，浏览器里会先显示一页确认，写明发起登录的设备 IP，确认是本人后再点按钮。

App 里只能**登录**，不能**绑定**：绑定请在浏览器里打开面板完成。

## 第三步：开启 Discord 通知机器人

### 创建机器人

1. 在同一个应用里进入左侧 **Bot**，点 **Reset Token**，复制 **Bot Token**（形如 `xxxx.yyyy.zzzz`）。Token 等于机器人的密码，不要发给别人。
2. 同一页的 **Privileged Gateway Intents** 全部**不用打开**：面板只用 REST 接口发私信，不连 Gateway、不读任何消息。
3. 进入 **OAuth2 -> URL Generator**，Scopes 勾 **bot**（Bot Permissions 不用勾），打开生成的链接，把机器人拉进**你的 Discord 服务器**。

### 在面板里填写

还是 `系统设置 -> 系统配置 -> Discord`，下半部分「Discord 通知机器人」：

| 选项 | 说明 |
| --- | --- |
| 启用 Discord 通知 | 总开关。打开后工单、规则异常、线路切换、自动换 IP、安全巡检、每日简报都会私信给绑定了 Discord 的人 |
| 主机上下线通知 | 主机掉线 / 恢复时私信管理员（和 Telegram 的「主机状态通知」对应，各自独立） |
| 到期提醒 / 流量提醒 | 私信用户。提前天数和剩余百分比阈值沿用「Telegram 机器人」卡片里的设置 |
| Bot Token | 保存时面板会向 Discord 验证一次，并显示机器人的名字。保存后只显示打码值 |

保存后，先在 `个人资料 -> Discord` 绑定你自己的 Discord，再回来点 **发送测试消息**。

规则上的「异常通知」、转发组的「切换通知」、主机上的「流量告警」「续费提醒」这些开关，Telegram 和 Discord 共用。

公告的「TG 推送」目前只发 Telegram，不发 Discord。

### 私信隐私（重要）

Discord 只允许机器人私信**和它在同一个服务器里、并且允许「服务器成员私信」**的人。所以：

- 让用户加入你拉了机器人的那个 Discord 服务器；
- 用户在该服务器的 **隐私设置** 里打开「允许来自服务器成员的私信」（Discord 默认是开的，但很多人关掉了）。

私信被 Discord 拒收（403）时，面板会记下来，**6 小时内不再给这个人发**（别人照常发），并在他的 `个人资料 -> Discord` 里提示怎么打开私信；改好以后点「重新尝试」立刻验证。

### 每个人自己的通知开关

绑定了 Discord 的人在 `个人资料 -> Discord` 里能按类别开关通知（主机上下线、规则异常、线路切换只有管理员有；工单消息和每日简报人人都有）。**这些开关和 Telegram 机器人菜单里的「通知设置」是同一份**：在任何一边关掉，两边都不再发。

### 出错时会怎样

- Discord 限流（429）：按 Discord 给的等待时间重试，最多等 30 秒。
- Bot Token 失效（被重置了，401）：面板**自动关闭 Discord 通知**，并在面板日志和事件时间线里记一条，等管理员填新的 Token 再打开。
- 消息太长：超过 Discord 的 2000 字上限时截断，并注明「完整内容请到面板查看」。
- 通知正文里用户填写的内容（工单标题、主机名等）会被转义，不会变成链接或格式；消息不会 @ 任何人，也不展开链接预览。

## 安全说明

- 授权走 OAuth 2.0 授权码（带 client_secret），并附带 PKCE（S256）。`state` 和 PKCE 校验码只保存在面板内存里，10 分钟有效、只能用一次；浏览器里另有一个 HttpOnly、SameSite=Lax 的绑定 cookie，回调时两者都对得上才继续 —— 别人发给你的回调链接在你的浏览器里不起作用。面板重启会让正在进行中的 Discord 登录作废，重新点一次按钮即可。
- 面板拿到 Discord 的身份以后立刻吊销 access_token，不保存任何 Discord 令牌。
- 登录成功后跳回的页面只接受面板内的相对路径，防止被拿来跳转到别的网站。
- 授权码、令牌不会出现在网址、日志或数据库里；失败时网址里只有一个简短的错误码。
- 登录、绑定、解绑、Discord 注册都会记到事件时间线（`account.*`）。
- Client Secret 和 Bot Token 存在系统设置里，读取时打码；导出诊断包时会被脱敏。

## 常见问题

| 现象 | 原因和处理 |
| --- | --- |
| Discord 页面报 `Invalid OAuth2 redirect_uri` | Developer Portal 里 Redirects 和面板设置页显示的不一致（协议、域名、端口、路径都要一样） |
| 登录页提示「还没绑定面板账号」 | 先用密码登录，在个人资料里绑定 Discord；或者管理员打开「允许用 Discord 注册新账号」 |
| 提示「邮箱还没有验证」 | 去 Discord 的 用户设置 › 我的账号 验证邮箱，或者授权时别取消勾选邮箱 |
| 提示「向 Discord 换取登录凭据失败」 | 面板服务器访问不了 discord.com，或 Client Secret 填错 / 被 Reset 过了。看面板日志里 `[DiscordAuth]` 开头的那一行 |
| 测试消息提示「Discord 拒绝了这条私信」 | 你和机器人不在同一个服务器，或者关了「服务器成员私信」，见上面「私信隐私」 |
| Discord 通知自己关掉了 | Bot Token 失效（在 Developer Portal 被重置过）。填新的 Token 再打开 |
