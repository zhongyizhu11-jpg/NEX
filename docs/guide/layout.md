# 界面与精简布局

NEX 有两套布局密度：**标准**和**精简**。数据和功能完全一样，只是摆法不同。

| | 标准 | 精简 |
| --- | --- | --- |
| 适合 | 第一次用、人少机器少 | 日常运维、商用面板、规则和主机多 |
| 字号 / 行高 | 正文 15～17px | 正文 13～15px |
| 卡片、控件 | 留白充足、大圆角 | 更矮更密、小圆角，一屏多看 30%～40% |
| 说明文字 | 每一项带一句介绍 | 介绍收起来，只留状态、数值、报错和警告 |
| 侧栏 | 13.5rem，含个人资料、系统设置 | 12rem；个人资料、系统设置只在右上角账户菜单里 |
| 页头 | 标题 + 介绍 + 状态点 + 走势 | 只留标题和主操作 |

## 谁说了算

1. **个人偏好**：个人资料 › 界面 › 布局，三选一：跟随站点 / 标准 / 精简。只改这个账号看到的界面。
2. **站点默认**：设置 › 个性化 › 布局（管理员）。没有自己选过的账号都按它走，适合给所有客户统一一种。
3. 右上角账户菜单里的「精简布局」是个人偏好的快捷开关，点一下当场切换。

## 和主题的关系

精简只改尺寸，不改颜色。经典、极光、墨金、珍珠等所有界面主题都能配精简，配色、页面底色、卡片风格照旧生效。

## 手机

手机上精简同样生效，但按钮、输入框保持 36px 以上的触控区，底部标签栏和顶栏不变。列表页（规则、主机、链路）的「新建」在页头右边，搜索收成分类条右边的放大镜图标，点开才出现一行；有搜索词或筛选条件时图标带一个点。
