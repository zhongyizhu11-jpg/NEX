# 界面与精简布局

NEX 的界面是一套紧凑的后台外壳：控件和卡片不留多余的白、说明文字收起来只留状态和数值、侧栏窄、列表页的分类条和搜索并排、各页的「新建」在页头右边、设置页的保存按钮收在底下一条保存栏里。顶栏和手机底部标签栏不动。数据和功能不随布局变。

在这个基础上有两种布局：**标准**和**精简**。两种只差一件事：**总览、转发、主机、链路**四个主页面。

| | 标准 | 精简 |
| --- | --- | --- |
| 四个主页面 | 按原来的样子：留白充足、字号大一档、页头带状态点和走势、新建在搜索行 | 条状：桌面上转发 / 主机 / 链路就是一张表（地址画成药丸，开关和编辑排在操作列），3D 图和地图照旧可切；手机上是一个圆角容器里的两行列表行。说明收起、新建在页头、手机上搜索收成图标；总览的地图矮一档、「快速开始」折成一行 |
| 其余页面、弹窗、设置、顶栏、侧栏 | 一样 | 一样 |

## 谁说了算

1. **个人偏好**：个人资料 › 界面 › 布局，三选一：跟随站点 / 标准 / 精简。只改这个账号看到的界面。
2. **站点默认**：设置 › 个性化 › 布局（管理员）。没有自己选过的账号都按它走，适合给所有客户统一一种。
3. 右上角账户菜单里的「精简布局」是个人偏好的快捷开关，点一下当场切换。

## 和主题的关系

布局只改尺寸，不改颜色。经典、极光、墨金、珍珠等所有界面主题都能配两种布局，配色、页面底色、卡片风格照旧生效；四个主页面在标准布局下用的圆角、字号就是主题自己给的。

## 手机

手机上按钮、输入框保持 36px 以上的触控区，底部标签栏和顶栏不变。精简下列表页（规则、主机、链路）的「新建」在页头右边，搜索收成分类条右边的放大镜图标，点开才出现一行；有搜索词或筛选条件时图标带一个点。标准下规则 / 主机页头的「···」在状态点那一行的右边、不描边，不压在走势线上。「更多」页直接列出系统设置的各个分区（通用 / 通知 / 维护），点一项进去；深色外观在顶栏的调色盘里切。

## 界面语言（English）

面板默认中文，也可以切成英文：

- **登录页 / 首次部署向导**：右上角的「语言 / Language」按钮，三选一：自动（跟随浏览器）/ 简体中文 / English。
- **登录之后**：右上角账户菜单里的「语言」一行，点一下中英互换，不用刷新。

选择记在这台设备的浏览器里（不跟账号走）。换一台设备或清了浏览器数据就回到「自动」：浏览器语言里先出现中文就是中文，先出现英文就是英文，都没有按中文。日期、时间的写法跟着界面语言变。

英文界面是在页面画出来之前按词典把中文换成英文（词典在 `client/src/i18n/en.json`），所以有几类文字会**保持中文**：

- **你自己填的内容**：主机名、规则名、隧道名、备注、公告正文、套餐说明、日志等，原样显示，不翻译。
- **一部分服务端报错和通知**：常见的报错（主机不存在、无权操作、端口被占用等）有英文；词典里没有的整句保持中文，不会半句中文半句英文。
- **少数不常用的页面**：订阅、计费、运维看板等页面里还有部分文字是中文，后续版本陆续补齐。

开发者补词典：`pnpm i18n:report` 列出各页面的覆盖率，`pnpm i18n:report -- --missing rules` 列出某一组还没有英文的文字。
