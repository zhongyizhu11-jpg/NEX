# 界面与精简布局

NEX 的界面是一套紧凑的后台外壳：控件和卡片不留多余的白、说明文字收起来只留状态和数值、侧栏窄、列表页的分类条和搜索并排、各页的「新建」在页头右边、设置页的保存按钮收在底下一条保存栏里。数据和功能不随布局变。

在这个基础上有两种布局：**标准**和**精简**。两种只差一件事：**总览、转发、主机、链路**四个主页面的卡片。

| | 标准 | 精简 |
| --- | --- | --- |
| 四个主页面的卡片 | 留白充足、字号大一档、大圆角 | 更矮更密，一屏多看几张 |
| 其余页面、弹窗、设置 | 一样 | 一样 |

## 谁说了算

1. **个人偏好**：个人资料 › 界面 › 布局，三选一：跟随站点 / 标准 / 精简。只改这个账号看到的界面。
2. **站点默认**：设置 › 个性化 › 布局（管理员）。没有自己选过的账号都按它走，适合给所有客户统一一种。
3. 右上角账户菜单里的「精简布局」是个人偏好的快捷开关，点一下当场切换。

## 和主题的关系

布局只改尺寸，不改颜色。经典、极光、墨金、珍珠等所有界面主题都能配两种布局，配色、页面底色、卡片风格照旧生效；四个主页面的卡片在标准布局下用的圆角、字号就是主题自己给的。

## 手机

手机上按钮、输入框保持 36px 以上的触控区，底部标签栏和顶栏不变。列表页（规则、主机、链路）的「新建」在页头右边，搜索收成分类条右边的放大镜图标，点开才出现一行；有搜索词或筛选条件时图标带一个点。「更多」页直接列出系统设置的各个分区（通用 / 通知 / 维护），点一项进去；深色外观在顶栏的调色盘里切。
