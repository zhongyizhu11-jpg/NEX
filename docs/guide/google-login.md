# Google 登录

开启后，登录页会多一个「使用 Google 登录」按钮。默认只有**已经绑定过 Google 的面板账号**能用；要不要让陌生的 Google 账号直接注册新账号，由管理员决定。

## 开始之前

- 面板要有一个固定的公开地址，并且是 **HTTPS**（Google 不接受 http 回调地址，`localhost` 除外）。在 `系统设置 -> 系统配置 -> 面板地址` 里填好并保存，例如 `https://panel.example.com`。
- 面板服务器要能访问 `accounts.google.com`、`oauth2.googleapis.com` 和 `www.googleapis.com`。服务器在访问不了 Google 的网络里时，用户会看到「向 Google 换取登录凭据失败」。

## 第一步：在 Google Cloud Console 创建 OAuth 客户端

1. 打开 [Google Cloud Console](https://console.cloud.google.com/)，新建（或选一个）项目。
2. 进入 `API 和服务 -> OAuth 同意屏幕`：
   - 用户类型选 **外部**（只给自己公司 Google Workspace 用的话可以选「内部」）；
   - 填应用名称（比如「NEX 面板」）、用户支持邮箱、开发者联系邮箱；
   - 「范围」不用额外添加 —— 面板只要 `openid`、`email`、`profile` 三项基础信息；
   - 测试阶段只有「测试用户」里的账号能登录；正式给大家用之前点 **发布应用**。
3. 进入 `API 和服务 -> 凭据 -> 创建凭据 -> OAuth 客户端 ID`：
   - 应用类型选 **Web 应用**；
   - 「已获授权的重定向 URI」添加一条，**和面板设置里显示的完全一致**：

     ```text
     https://panel.example.com/api/auth/google/callback
     ```

     （就是「面板公开地址」后面接 `/api/auth/google/callback`。设置页里有现成的一键复制。）
   - 「已获授权的 JavaScript 来源」不用填。
4. 创建完成后会给出 **客户端 ID**（`…apps.googleusercontent.com`）和 **客户端密钥**（`GOCSPX-…`）。

::: warning 面板公开地址改了，回调地址也要跟着改
回调地址是用「面板公开地址」拼出来的。换了域名或端口之后，要回 Google Cloud Console 把新的回调地址加进去，否则 Google 会报 `redirect_uri_mismatch`。
:::

## 第二步：在面板里填写

进入：

```text
系统设置 -> 系统配置 -> Google 登录
```

| 选项 | 说明 |
| --- | --- |
| 启用 Google 登录 | 总开关，默认关。没填面板公开地址、客户端 ID 或密钥时开不了 |
| 允许用 Google 注册新账号 | 默认关：只有已经绑定过的账号能用 Google 登录。打开后还要同时满足「开放注册」和邮件设置里的邮箱白名单 |
| 客户端 ID / 客户端密钥 | 上一步拿到的两项。密钥保存后只显示打码值，输入框留空 = 不修改 |
| 只允许这些邮箱域名 | 可选，逗号分隔，例如 `example.com, corp.example.org`。留空 = 任何 Google 账号。子域名也算（`mail.example.com` 属于 `example.com`）。对登录、绑定、注册都生效 |

保存后，登录页就会出现「使用 Google 登录」。

## 用户怎么绑定

1. 先用用户名 + 密码登录面板（要在「面板公开地址」打开的面板里）。
2. 打开 `个人资料 -> Google 账号`，点 **绑定 Google**，在 Google 页面选择账号。
3. 回到个人资料，显示「已绑定」和对应的 Google 邮箱。以后在登录页点「使用 Google 登录」即可。

解除绑定也在这里。解除前要确认账号还有别的登录方式：用 Google 注册的账号一开始没有密码，要先在同一块里 **设置登录密码**（或者添加通行密钥），才能解除绑定。

## 账号怎么对应

- 面板只认 Google 账号的 **sub**（Google 给每个账号的永久编号），不认邮箱。Google 账号改了邮箱，绑定不受影响；面板里显示的 Google 邮箱会在下次登录时更新。
- **不会按邮箱自动合并账号。** 一个没绑定过的 Google 账号，哪怕邮箱和某个面板账号一模一样，也不会直接登录进那个账号 —— 会提示「这个 Google 账号还没绑定面板账号：请先用密码登录，在 账号设置 里绑定 Google」。这样别人拿一个同名邮箱的 Google 账号也进不了你的面板账号。
- 允许注册时，新账号的用户名取邮箱 `@` 前面的部分（被占用就加数字，比如 `alice2`），邮箱记为已验证，权限和自助注册的新用户一样（需要管理员开通）。这个邮箱已经是某个面板账号的用户名或邮箱时，不会再建一个新账号，同样提示去绑定。
- 一个 Google 账号只能绑定一个面板账号，一个面板账号也只能绑定一个 Google 账号。
- 停用的账号、维护模式，和密码登录的规则完全一样。
- 开了 [邀请返利](./referrals.md) 时，从邀请链接打开注册页再点「使用 Google 登录」，邀请码会一起带过去，新账号照样记上邀请人。开了「必须邀请注册」时，没有有效邀请码的 Google 账号不能注册新账号（已经绑定过的账号登录不受影响）。

## 双重验证

账户开了双重验证（2FA）时，用 Google 登录之后**仍然要输入 2FA 验证码**。面板没法知道 Google 那边有没有做过两步验证，Google 账号被盗也不应该绕过面板自己的 2FA。

## 在 App 里使用

Google 不允许在 App 内嵌的网页里登录（会报 `disallowed_useragent`），所以 App 里点「使用 Google 登录」会打开**系统浏览器**：

1. 在浏览器里选择 Google 账号；
2. 看到「请回到 NEX App」后切回 App，几秒内自动登录（App 每两秒问一次面板）；
3. 如果浏览器和 App 的网络出口 IP 不一样（比如一个走 Wi-Fi、一个走流量），浏览器里会先显示一页确认，写明发起登录的设备 IP，确认是本人后再点按钮。

限制：

- App 里只能**登录**，不能**绑定**：绑定请在浏览器里打开面板完成，绑好以后 App 里就能用。
- 面板要用「面板公开地址」能访问到（浏览器打开的是公开地址上的授权入口）。

## 安全说明

- 授权走 OAuth 2.0 授权码 + PKCE（S256），并带 OpenID Connect 的 `nonce`。`state`、PKCE 校验码和 `nonce` 只保存在面板内存里，10 分钟有效、只能用一次；浏览器里另有一个 HttpOnly、SameSite=Lax 的绑定 cookie，回调时两者都对得上才继续 —— 别人发给你的回调链接在你的浏览器里不起作用。面板重启会让正在进行中的 Google 登录作废，重新点一次按钮即可。
- 面板自己校验 Google 返回的 ID Token：RS256 签名（对 Google 公布的公钥，带缓存）、签发方、受众（必须是你的客户端 ID）、有效期、`nonce`，以及邮箱已验证。
- 登录成功后跳回的页面只接受面板内的相对路径，防止被拿来跳转到别的网站。
- 授权码、令牌不会出现在网址、日志或数据库里；失败时网址里只有一个简短的错误码。
- 登录、绑定、解绑、Google 注册都会记到事件时间线（`account.*`）。
- 客户端密钥存在系统设置里，读取时打码；导出诊断包时会被脱敏。

## 常见问题

| 现象 | 原因和处理 |
| --- | --- |
| Google 页面报 `redirect_uri_mismatch` | Google Cloud Console 里的回调地址和面板设置页显示的不一致（协议、域名、端口、末尾路径都要一样） |
| Google 页面报 `access_blocked` / 只有部分人能登录 | 同意屏幕还在「测试」状态，去 OAuth 同意屏幕点「发布应用」，或把账号加进测试用户 |
| 登录页提示「还没绑定面板账号」 | 先用密码登录，在个人资料里绑定 Google；或者管理员打开「允许用 Google 注册新账号」 |
| 提示「向 Google 换取登录凭据失败」 | 面板服务器访问不了 Google，或客户端密钥填错了。看面板日志里 `[GoogleAuth]` 开头的那一行 |
| 提示「登录请求已过期或无效」 | 授权页停留超过 10 分钟、面板中途重启过，或者从别的浏览器打开了回调链接。重新点一次按钮 |
| 绑定时提示要在「面板公开地址」上操作 | 你现在是通过 IP 或别的域名打开的面板，按提示换到公开地址上再绑定 |
