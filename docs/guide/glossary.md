# 术语表

面板里有几样东西名字相近、又互相引用。这一页把它们各指什么说清楚；界面上的叫法按这里来。

| 叫法 | 指的是什么 | 在哪里 |
| --- | --- | --- |
| **订阅** | 客户端订阅：一条订阅地址，客户端（Clash、sing-box、Shadowrocket 等）拉它拿到你的落地节点和经中转的线路。只指这个。买的套餐叫 **套餐**，不叫订阅 | 侧边栏「订阅管理」；管理员看全站的在「订阅运营」；买的套餐在「我的套餐」 |
| **链路** | 机器和机器之间搭好的、可以被转发规则引用的那些东西：隧道、端口转发、转发链、转发组、入口组、出口组、叠加、节点池 | 侧边栏「链路管理」 |
| **线路** | 一条转发实际走的路：从入口进，经过中转或隧道，到落地。每条转发规则就是一条线路。一条规则开了 **线路组**，就挂着几条线路（主线路、备用线路），出问题自动换 | 「链路管理 › 线路概览」（管理员）、「网络拓扑 › 我的线路」、规则卡上的「主备 · 主线路」 |
| **隧道** | 两台或更多台自己的机器之间的一条加密通道（NEX / GOST / Nginx Stream），入口进、出口出，中间可以经过几台中转。转发规则可以「走隧道」 | 「链路管理 › 隧道链路」；单连接叠加的隧道在「更多 › 叠加」 |
| **节点池** | 几台机器放在一起，当一个整体用。有两种用途：**中转池**（线路里一层选它，面板按整条链的延迟在这几台里挑）和 **落地池**（见下） | 「链路管理 › 更多 › 节点池」 |
| **落地池** | 节点池的一种：几台机器开 **同一份** 落地（协议、端口、密钥一样），订阅里整个池只出一条节点 | 「链路管理 › 更多 › 节点池 › 新建 › 落地池」 |
| **落地节点** | 在一台机器上开的一个入站，客户端最后连到的那一跳。新建只有一个主入口 | 「订阅管理 › 我的节点 › 新建 › 在我的机器上开一个」 |
| **端口转发** | 不经过隧道：一台入口机直接把一个端口转到目标。两处会看到这个词：转发规则的类型「端口转发」，和「链路管理 › 端口转发」里预先配好的端口转发资源（选好入口机和转发工具，规则直接选它） | 「转发规则」新建时选类型；「链路管理 › 端口转发」 |
| **转发组** | 几台入口机组成一组，主备或负载均衡，规则挂在组上，任何一台坏了自动换。和它同类的还有 **入口组**（DNS 解析到几台入口）、**出口组**（几台出口按策略分）和 **转发链**（按顺序一台转一台） | 「链路管理 › 更多 › 转发 / 转发组、入口组、出口组、转发链」 |

## 链路管理的页签

2.3.506 起分类条上只摆三个最常用的，其余在最后一格 **更多** 里，按用途分组。页签本身和地址栏里的 `?tab=` 都没变，老链接照常能打开。

| 页签 | 位置 | `?tab=` |
| --- | --- | --- |
| 隧道链路 | 分类条（默认打开） | `tunnels` |
| 端口转发 | 分类条 | `ports` |
| 线路概览 | 分类条 | `routes`（老链接 `lines` 也到这里） |
| 转发链 | 更多 › 转发 | `chains` |
| 转发组 | 更多 › 转发 | `groups` |
| 入口组 | 更多 › 转发 | `entries` |
| 出口组 | 更多 › 转发 | `exits` |
| 叠加 | 更多 › 隧道 | `aggregates` |
| 节点池 | 更多 › 线路 | `pools` |

选中「更多」里的一页时，那一格写的就是它的名字。

## 能分享的地址

| 地址 | 打开什么 |
| --- | --- |
| `/rules?line=<规则 id>` | 这条线路的详情（线路组）。网络拓扑、我的线路、订阅内容、线路概览点进去都是这一个 |
| `/tunnels?line=<规则 id>` | 同一个线路详情，开在「链路管理 › 线路概览」里（管理员） |
| `/rules?edit=<规则 id>` | 这条规则的编辑框 |
| `/rules?diagnose=<规则 id>` | 这条规则的诊断框 |
| `/hosts?host=<主机 id>` | 这台主机的详情 |
| `/topology?rule=<id>`、`?tunnel=<id>`、`?group=<id>` | 网络拓扑，聚焦这一条的路径 |
| `/looking-glass?method=iperf3-pair&tunnel=<隧道 id>` | 网络测试的 iperf3 对拉，选好这条隧道 |
| `/client-subscriptions?create=node` | 订阅管理，直接打开「在我的机器上开一个」 |
