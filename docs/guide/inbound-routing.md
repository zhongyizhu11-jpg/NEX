# 落地节点分流（按解锁选出口）

一台落地往往只解锁一部分服务：美西机解 Netflix 不解 ChatGPT，港机反过来。给落地节点加 **分流** 之后，可以按服务或域名把这个端口的一部分流量从 **另一台落地** 出去，其余照旧直连：

```text
客户端 ──▶ 港机落地节点（sing-box）
              ├─ Netflix、Disney+ ──Shadowsocks──▶ 美西落地 ──▶ Netflix
              ├─ 广告域名 ──▶ 拒绝
              └─ 其余 ──▶ 直连
```

在「我的节点」里编辑一个自建节点，找到 **分流** 一段，点「加一条」：

1. **选服务**：Netflix、Disney+、YouTube Premium、TikTok、ChatGPT、Claude、Gemini、Grok、Perplexity（和主机「解锁检测」是同一份清单），也可以填自定义域名（一行一个，`example.com` 同时匹配它的子域名）。
2. **选去哪**：
   - **直连**：从这台落地自己出去（用来给前面的规则开例外）。
   - **拒绝**：直接断开。
   - **走另一台落地**：选一台 Shadowsocks 落地入站。下拉里只列你能用的（自己的，或管理员开放的「落地出口」入站且你有那台主机的权限）；选好后会显示那台落地对所选服务的最新检测结论。
   - **自动：挑解锁的落地**：面板每次下发配置时，在你能用的 Shadowsocks 落地里挑一台 **在线**、**最新一次解锁检测里所选服务都「可用」** 的。几台都行时挑最近检测过的那台。检测结果变了（手动检测或计划检测），下一次心跳配置就跟着换，不用回来改。

规则按顺序匹配，第一条命中的生效；没命中任何一条的流量直连，和没设分流时一样。

::: tip 不用升级 Agent
分流做在落地机的 sing-box 上：面板生成配置时多写几条路由规则（先嗅探 TLS SNI / HTTP Host / QUIC 拿到域名，再按域名分），Agent 只是照常把配置推下去。已经装好的 Agent 和 sing-box 都不用升级。没设分流的节点生成的配置一字不差，不会因为面板升级而重启。
:::

## 出口失效时怎么处理

- **点名的落地被停用、没有可用地址、你没权限用了**：这部分流量 **拒绝**，不会悄悄改成直连 —— 你选另一台落地就是不想从这台的 IP 出去。编辑框里每条分流下面写着「现在：……」，能看到实际去了哪、为什么。
- **点名的落地离线**：照样指过去（面板看到的离线不一定真断），回来了不用重新下发。
- **自动挑不出来**（没有检测结果，或者都不解锁）：先 **直连**，有了可用的落地再自动换过去。
- 正被别的节点分流点名使用的落地入站不能删除，先改掉那边的分流。
- 落地入站改了端口、密码或启停，用它的节点所在的主机会马上收到新配置。

自动挑选依赖解锁检测结果：在「主机」详情里对落地主机点「检测解锁」，或者打开计划检测（每天 / 每周）。
