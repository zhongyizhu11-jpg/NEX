# 邀请返利

邀请返利让老用户把面板推荐给朋友：朋友用邀请链接注册，之后**花钱购买套餐**时，按该套餐设置的比例把实付金额的一部分返到邀请人的余额里。

返多少按套餐分别设置：利润薄的套餐可以不返，引流套餐可以多返。

## 开启

管理员进入「账单与兑换」，切到「邀请返利」标签页：

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 开启邀请返利 | 关 | 关闭时不返利，用户侧边栏也不显示「邀请返利」入口 |
| 返利方式 | 仅首单返利 | 「仅首单返利」：每个被邀请人只有第一笔符合条件的购买会返利；「每单返利（含续费）」：被邀请人每次购买、续费都返 |
| 必须邀请注册 | 关 | 只在开启邀请返利时生效。打开后注册必须填写有效的邀请码，否则拒绝注册 |

开启后还要给套餐设比例，否则所有套餐都是 0（不返）。

## 给套餐设置返利比例

在「套餐管理」里编辑套餐，填写「邀请返利比例（%）」：

- 范围 0 到 100，最多两位小数，例如 `10`、`12.5`、`0.75`。
- 填 `0` 表示这个套餐不返利。
- 比例按套餐保存，修改后只影响之后的订单，已经返过的记录不变。

套餐卡片和表格里会显示每个套餐的返利比例。

## 返多少

```
返利金额 = 向下取整（被邀请人实付金额 × 返利比例）
```

- **实付金额**是用了折扣码之后真正付的钱，不是标价。
- 金额精确到分，不足一分的部分舍去；算出来不足一分就不返。
- 返利直接进入邀请人的余额，余额流水里记为「邀请返利」，备注里写明套餐名和打了码的被邀请人账号。

例：套餐 9.99 元，比例 10.5%，返利 = 向下取整（999 × 10.5%）= 104 分，即 1.04 元。

## 什么情况会返

只有被邀请人**真金白银买套餐**才返：

- 在线支付购买或续费套餐（支付宝、微信、易支付、USDT、Stripe 人民币订单）。
- 用余额购买或续费套餐，包括余额自动续费。

以下情况**不返**：

- 余额充值。充值的钱之后拿去买套餐时会返一次，充值时再返就重复了。
- 兑换码兑换套餐或余额、管理员手动分配套餐、测试订单、0 元套餐。
- 在线支付确认后无法开通、订单金额转入余额的情况（这笔钱没有变成套餐）。
- 被邀请人没有邀请人、邀请人账号已停用或已删除、该套餐比例为 0。
- **非人民币订单**：Stripe 可以设成美元等其他币种，而余额是人民币，面板没有可靠的汇率换算，这类订单不返利，面板日志会记一行说明。
- 「仅首单返利」模式下，这个被邀请人已经返过一次。

同一笔订单无论支付回调重复几次、维护任务重试几次，都只返一次。返利过程中出现任何错误只会撤销返利本身，被邀请人的购买照常完成。

## 用户侧：邀请返利页

开启后，用户侧边栏出现「邀请返利」，页面里有：

- 自己的邀请码和完整的邀请链接（`https://你的面板地址/login?mode=register&invite=邀请码`），都可以一键复制。邀请码第一次打开这个页面时生成，8 位，不含容易认错的 0、O、1、I、L。
- 已邀请人数和累计返利。
- 返利明细：时间、打码后的好友账号（如 `a***e`）、套餐、实付金额、比例、返利金额。
- 可返利的套餐列表：商店里可见、比例大于 0 的套餐和各自的比例。

「邀请返利」也可以在「系统设置」的侧边栏菜单开关里单独隐藏。

## 注册时的邀请码

- 打开邀请链接会直接进入注册页，并自动填好、锁定邀请码。链接里写成 `?ref=邀请码` 也认。
- 没有链接的用户可以在注册页手动填写（选填）。
- 邀请码填错、或者邀请人账号已停用：默认安静忽略，照常注册，只是不绑定邀请人；如果开了「必须邀请注册」，则拒绝注册并提示填写有效邀请码。
- 邀请关系在注册时绑定一次，用户自己无法修改。
- 开了 [Google 登录](./google-login.md) 并允许用 Google 注册时：在邀请链接打开的注册页点「使用 Google 登录」，邀请码同样生效；「必须邀请注册」对 Google 注册同样有效。

## 管理员查看和修改

- 「账单与兑换 › 邀请返利」下方是所有返利记录，可以按邀请人用户名筛选，显示来源订单号或余额流水号。
- 「用户管理」打开某个用户的详情，可以看到他的邀请人、邀请了多少人、累计返利，并可以修改或清除邀请人。不能把邀请人设成他自己，也不能形成循环邀请（例如 A 邀请了 B，就不能再把 B 设为 A 的邀请人）。
- 删除用户时，被他邀请的用户的邀请关系会一并清除；已经产生的返利记录保留。
