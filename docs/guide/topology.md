# 网络拓扑

「网络拓扑」把整个面板的转发按**流量先后**画成一张图：左边是入口，往右依次是中转、出口 / 落地，最右边是目标。一眼看清哪条规则走了哪几台机器、哪台机器被哪些规则和隧道共用、哪一段停了或者坏了。

入口在侧边栏「链路管理」下面的 **「网络拓扑」**（手机上在「更多」里）。管理员可以在「系统设置 → 侧边栏」里把它关掉。

## 和首页地图的区别

| | 首页地图 | 网络拓扑 |
| --- | --- | --- |
| 怎么摆 | 按地理位置 | 按流量先后分列：入口 → 中转 → 出口 / 落地 → 目标 |
| 画什么 | 主机之间的隧道和转发线 | 主机、外部目标、落地入站、入口组 / 转发组，以及它们之间每一种连线 |
| 适合 | 看整体分布 | 排查「这条规则到底经过谁」「这台机器停了会影响谁」 |

## 图上有什么

### 节点

| 节点 | 说明 |
| --- | --- |
| 主机 | 每台主机只出现一次。左边的色条按角色上色：**入口**蓝、**中转**紫、**出口**橙、**落地**绿（一台机器同时担任几个角色时按这个顺序取第一个，悬停能看到全部角色）。右上角的小圆点是在线（绿）/ 离线（红） |
| 外部目标 | 转发的目标地址不是任何一台受管主机时画成圆角胶囊，按「地址:端口」合并；写的是域名就原样显示域名，不解析 |
| 落地入站 | 在受管主机上开的落地节点（VLESS、Trojan、Hysteria2……），挂在所在主机后面 |
| 入口组 / 转发组 | 客户端连的那个域名：入口组、主备转发组画成一个节点，连到每台成员主机 |

目标地址正好是某台受管主机的地址（IP、入口 IP 或开着的 DDNS 域名）时，连线落在那台主机上，它就是「落地」；落在它某个落地入站的端口上时，那条规则也会记在「主机 → 入站」这段上。

### 连线

| 连线 | 怎么画 |
| --- | --- |
| 转发规则 | 灰色实线：入口主机 → 目标 |
| 隧道 | 蓝色：入口 → 隧道中转 → 出口（多出口按这条规则实际分到的出口） |
| 转发链 | 紫色：入口（或入口组的每台）→ 成员 1 → … → 最后一台 → 目标 |
| 线路组路径 | 琥珀色：每条路径各自从入口经过它的中转到它的落地 |
| 落地入站 | 青色点线：主机 → 入站 |
| 入口组 / 转发组 | 靛蓝虚线：组 → 成员主机 |

- **虚线**：整段都停用了。
- **红色**：开着但不通（规则没在跑、隧道没起来、中继断了）。
- **橙色**：部分异常（几条规则里有的通有的不通，或者探测在丢包）。
- **粗细**：经过这一段的规则越多越粗。

同一对节点之间同一种连线只画一条，悬停能看到经过它的规则、协议、端口和最近一次延迟。

## 操作

- **缩放 / 平移**：滚轮缩放，按住拖动平移；手机上单指拖动、双指捏合。右上角的 `+` `−` 和「适应窗口」按钮把整张图缩放到刚好放下。
- **点节点**：右侧（手机上是底部弹出的面板）列出用着它的规则、隧道、转发链 / 组和各自的状态；「打开」跳到对应的转发规则页或链路管理页（已按名称搜好），「聚焦」只亮出那一条的路径。
- **点连线**：列出经过这一段的规则和所属的隧道 / 组。
- **筛选**：顶部按连线种类开关；「外部目标」关掉后只看主机之间的结构；搜索框能搜主机名、地址、规则名和端口，匹配的节点高亮。
- **按用户看**（管理员）：右上角选一个用户，只看他的规则、隧道、转发组和入站。

### 聚焦一条规则、隧道或转发链

转发规则的「更多」菜单、隧道和转发链 / 转发组卡片的「更多」菜单、线路组面板底部都有 **「查看拓扑」**，点了打开这一页并聚焦它的路径，别的都变淡。地址栏会带上 `?rule=ID`、`?tunnel=ID` 或 `?group=ID`，可以直接收藏或发给别人；点「取消聚焦」回到全图。

## 普通用户看到什么

普通用户只看到**自己的**规则、隧道、转发组和落地入站，以及这些东西经过的主机。

- 经过的主机是自己的、被授权的，或者在共享给自己的链路里，会显示名字。
- 别人共享给你的隧道中转到的、你看不见的机器显示成「隐藏节点」，不显示名字、地址和编号。
- 你填的目标地址恰好是一台你看不见的受管主机时，按外部目标画，不会暴露那是一台受管主机。

## 数据从哪来

图每 30 秒左右刷新一次（面板端缓存 10 秒），用的都是现有数据：规则和隧道的运行状态、主机在线状态、最近 15 分钟的探测延迟、线路组的评分和逐跳探测。它不发起新的探测。
