# 界面主题

NEX 自带三套界面主题：**经典**、**珍珠**、**液态玻璃**。其余主题都是**主题包**，用到才装：不装的主题不进任何人的浏览器，也不占安装包里的页面体积。

| 来源 | 说明 |
| --- | --- |
| 官方主题库 | 深空、墨金、玫瑰、朱砂、靛蓝。随面板一起发布，点一下就装，不需要外网 |
| 上传压缩包 | 别人做好的主题包（ZIP 或 TAR.GZ） |
| 从链接安装 | 填一个压缩包直链，面板去下载 |

主题只改外观，功能和数据不变。深浅色、配色、页面底色、卡片风格、精简布局都照常在主题上叠加。

## 安装和切换

管理员进入「系统设置 › 个性化配置」：

1. 在「主题管理」里找到想要的主题，点 **安装**。官方主题库之外的主题，用 **上传压缩包** 或 **从链接安装**。
2. 装好的主题出现在上面的「界面主题」里，点一下在这一页试看，点 **保存主题** 后对所有人生效。
3. 顶栏的调色盘也列着装好的主题。管理员在那里选，等于改站点默认；普通用户在那里选，只改自己这台设备。

升级提示：从 2.3.524 及以前升级上来，如果站点默认正用着深空、墨金、玫瑰、朱砂或靛蓝，面板开机会自动把这一套装上，看到的和升级前一样。其余几套需要时再装。个人在顶栏调色盘里给自己选的主题只记在各自浏览器里，面板看不到：谁自己选过深空等现在要安装的主题，没装之前先按经典显示，管理员在官方主题库装上以后自动恢复成他选的那套。

## 更新和卸载

- 官方主题库里的主题：面板升级带来新版时，主题卡片上会出现「更新到 x.y.z」。
- 自己装的主题：勾上「替换已安装的同名主题」，再上传或用链接装一次新版本。
- **卸载**：正在用它的设备回到站点默认；如果它就是站点默认，站点默认改回经典。以后可以重新安装。
- **导出**：把装着的主题打回一个压缩包，带到别的面板去装。

面板备份和迁移会带着已安装的主题。

## 自己做一个主题

在「主题管理」点 **下载开发模板**，得到一个能直接安装的最小主题：

```text
theme.json   清单
theme.css    样式
README.md    说明
```

`theme.json` 的字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `apiVersion` | 是 | 固定写 `1` |
| `id` | 是 | 小写字母开头，小写字母、数字、连字符，3～32 个字符。装好以后不要改，升级靠它认出是同一套 |
| `name` | 是 | 显示的名字 |
| `version` | 是 | 三段版本号，例如 `1.0.0` |
| `description`、`author`、`homepage` | 否 | 显示在主题管理里 |
| `stylesheet` | 否 | 样式文件路径，默认 `theme.css` |
| `preview` | 否 | 设置页预览和调色盘小圆点用的颜色：`light` / `dark` 各写 `page`（页面底）、`card`（卡片）、`accent`（强调色），只收十六进制色 |

写样式的规矩只有一条：**每条规则都写在 `html[data-ui-theme="你的 id"]` 下面**，深色模式写 `html.dark[data-ui-theme="你的 id"]`。主题没被选中时这些规则一条都不生效。

```css
html[data-ui-theme="my-theme"] {
  --fx-l0-page: #f3f6f4;      /* 页面底 */
  --fx-l1-surface: #ffffff;   /* 卡片 */
  --fx-primary-fill: #2f8f6b; /* 主按钮、选中态 */
}

html.dark[data-ui-theme="my-theme"] {
  --fx-l0-page: #101614;
  --fx-l1-surface: #18211e;
}
```

尽量改设计令牌（`--fx-*` 变量，完整名单在源码的 `shared/design-tokens.css`），少直接改某个类：面板升级后类名可能变，令牌不会。官方主题库的五套主题（源码 `themes/official/`）是最完整的写法参考。

打包时 `theme.json` 放在压缩包根目录（外面套一层文件夹也可以，面板会自动去掉）。

### 限制

主题是管理员装的，样式却会进每个访客的浏览器，所以安装时面板会检查，不符合的装不上，并告诉你哪一处不对：

- 不能带脚本，压缩包里只能有 CSS、JSON、说明文字、图片（PNG、JPG、WebP、AVIF、GIF、SVG）和字体（WOFF、WOFF2、TTF、OTF）。
- 样式不能引用外网地址。`url()` 只能指向压缩包里的文件（安装时内联进样式）、`data:` 图片或字体，或者面板自带的 `/fonts/` 字体。
- 不支持 `@import`、`image-set()`、`expression()` 这类能带地址进来的写法；反斜杠只能转义类名里的标点（例如 `.md\:grid`）。
- 压缩包最大 6MB，解压后合计最大 16MB，单个文件最大 4MB，样式原文最大 512KB，最多 64 个文件；最多装 24 套主题。
- 从链接安装只能访问公网地址，不能访问内网和本机；跳转最多 4 次，60 秒超时。

## 常见问题

**装了主题，页面没变化？** 装好只是「有了」，要在「界面主题」里选中并保存，或者在顶栏调色盘里选。

**主题把按钮弄得看不见了？** 在面板地址后面加上 `?themeSafe=1` 打开，例如 `https://panel.example.com/settings?themeSafe=1`。这个标签页里只用内置的三套主题，照常进「个性化配置」换掉或卸载那套主题。关掉标签页，或者访问带 `?themeSafe=0` 的地址就退出安全模式。

**App 里能用装的主题吗？** 能。App 会到登录时填的面板地址去取主题样式。
